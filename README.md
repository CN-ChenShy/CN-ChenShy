# 评论系统

### 项目简介
* 本项目基于Java springboot搭建，maven管理。

* 前端采用原生HTML+JS

* 本项目只允许管理员admin发帖，其余权限只能看贴和发表评论

* 用vscode编写，插件Extension Pack for Java、Spring Boot Extension Pack。

* CZ.Quectel工作期间2026年4月17日
